# 飲食店向け勤怠管理アプリ

友人が店長を務める飲食店で給与の過払いが発生したことをきっかけに、
勤務記録を正確に残すために開発した勤怠管理アプリです。

PythonとStreamlitを用いて開発し、
Googleスプレッドシートに打刻データを保存しています。

現在は実店舗で試用しながら改善を進めています。

## 主な機能

- 出勤・退勤・休憩の打刻
- 勤務状態に応じたボタン制御
- 二重打刻の防止
- 打刻漏れや未完了記録の警告
- 日別・月別の勤務時間集計
- 打刻記録の訂正
- CSV出力

## 使用技術

- Python
- Streamlit
- pandas
- gspread
- Google Sheets API
- GitHub
- Streamlit Community Cloud

## 設計上の工夫

勤務記録の誤りを防ぐため、
勤務状態に応じて操作できるボタンを制御しています。

また、実働時間を確定できない記録は自動集計せず、
警告を表示する設計にしています。

給与計算については労務上の判断を伴うため実装せず、
正確な勤務記録を残す機能に範囲を限定しています。
